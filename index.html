API Configuration

This application uses the Google Gemini API to generate scripts. Since this app runs entirely in your browser without a backend server, you must provide your own free API key.

  1. Go to Google AI Studio .
  2. Sign in with your Google account.
  3. Click "Create API Key" and copy it.
Your key is stored securely in your browser's local storage and is never sent anywhere except directly to Google's API.
